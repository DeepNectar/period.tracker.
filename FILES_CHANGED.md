## 🔧 Required step after uploading code

Run **`PRIVACY_LOCK_SYNC.sql`** once in the **Supabase SQL Editor** (Dashboard → SQL Editor → paste → Run).
It is idempotent (safe to re-run). Without it, the lock still works locally on each device but cannot sync across devices.

## How the cross-device lock behaves

1. Enable the lock on any signed-in device → only a **hash + salt** (never the PIN) is stored in `user_prefs`.
2. Every other device on the same account receives it via Supabase Realtime (and on next focus/visibility refresh) → the PIN gate appears there too, requiring the **same PIN**.
3. Each device independently locks **immediately** whenever the app/site is closed, reloaded, or backgrounded.
4. Disabling on any device removes the lock everywhere.
5. Offline/guest mode: falls back to a local-only lock until the account syncs again.
